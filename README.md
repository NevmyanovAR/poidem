## Локальный запуск

Рекомендуется Node.js 22.13+ и npm. Из корня репозитория:

```powershell
cd frontend
npm ci
npm run dev
```

Точный адрес: **http://127.0.0.1:5173/**. Порт фиксирован. Для просмотра интерфейса в браузере токен не нужен; реальный вход требует backend и локального TELEGRAM_BOT_TOKEN. В dev /api/v1 проксируется в 8001; в production нужен явный VITE_API_BASE_URL и доступный HTTPS API. Подробности — [TELEGRAM_AUTH](docs/TELEGRAM_AUTH.md).

```powershell
npm run typecheck
npm run lint
npm run build
npm run test:production
```

Браузерные проверки используют Chrome, Playwright сам запускает сервер. `test:production` проверяет dist после `npm run build`. Дополнительно: `npx playwright install webkit`, затем `npm run test:devices` проверяет затронутые экраны в WebKit с параметрами iPhone и Chrome с параметрами Android. Production-просмотр: `npm run preview`, **http://127.0.0.1:4173/**.
