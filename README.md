# Пойдём?

Уточнение по присланному шрифту: По последнему указанию пользователя подключён присланный Nicoletta Script: в рукописных надписях «пойдем?» используется е вместо отсутствующей ё. Только светло-голубые акценты #B8E4FF, бордовый фон #550707 и основной белый текст #FFFFFF; насыщенный голубой исключён. PNG и пользовательский ввод не изменены. Условия некоммерческого использования шрифта сохранены. Подробности — [отчёт](docs/FINAL_REFINEMENTS.md).

Telegram Mini App для знакомств через совместные планы: сначала выбрать, что делать вместе, затем — с кем. MVP для дипломной работы и проверки гипотез на реальных пользователях.

## Текущий результат

Последнее уточнение 19.11.2026: только три визуальные правки — бокалы мэтча без наложений, SVG-звёздочка, фоновое фото на /home. Предыдущие изменения двух сборок/возраста отменены; деморежим, регистрация и единая сборка сохранены. Отчёт и снимки — [RELEASE_REVIEW](docs/RELEASE_REVIEW.md).

По заданию пользователя для этапа 2 создан интерактивный демонстрационный frontend на React + TypeScript + Vite. Девять экранов: приветствие, анкета, главная, каталог, карточка человека, создание плана, мои планы, вдохновение и мэтч. В обычном режиме каталог пуст до подключения backend, создание сохраняет локальный черновик. Деморежим включается в «Моей анкете» и показывает отдельные вымышленные планы/авторов и цикл отклик → принятие/отказ → мэтч.

Backend, Telegram-авторизация, база данных, бот и настоящие мэтчи не создавались. Редакционные идеи статические; источник реальных публикаций пока пуст. При выключенном деморежиме вымышленные публикации/совпадения скрыты. Включённый режим явно обозначен; его данные и состояние переключателя сохраняются отдельно от обычной анкеты/черновиков. Введённая анкета, фото и планы сохраняются в localStorage этого браузера. Реальной публикации, отправки приглашений и общения нет.

Прежняя конфигурация Cloudflare Pages сохранена: `frontend/.node-version`, `frontend/wrangler.toml`, Root directory frontend, Build command npm run build, output dist. Инструкция — [DEPLOYMENT](docs/DEPLOYMENT.md). Актуальная палитра централизована в `frontend/src/theme.css`: `#550707`, `#B8E4FF`, `#FFFFFF`; насыщенный голубой исключён. Публикация не выполнялась.

Обновление от 18.11.2026: [аудит замечаний, выполненные правки и вопросы](docs/CLIENT_REVIEW.md). Оригинальные PNG подключены без изменения файлов. Главная сокращена; идеи остаются во «Вдохновении». Изменения не опубликованы.

## Локальный запуск

Рекомендуется Node.js 22.13+ и npm. Из корня репозитория:

```powershell
cd frontend
npm ci
npm run dev
```

Точный адрес: **http://127.0.0.1:5173/**. Порт фиксирован. Переменные окружения и токен бота не нужны.

```powershell
npm run typecheck
npm run lint
npm run build
npm run test:production
```

Браузерные проверки используют Chrome, Playwright сам запускает сервер. `test:production` проверяет dist после `npm run build`. Дополнительно: `npx playwright install webkit`, затем `npm run test:devices` проверяет затронутые экраны в WebKit с параметрами iPhone и Chrome с параметрами Android. Production-просмотр: `npm run preview`, **http://127.0.0.1:4173/**.

## Источники и границы

Оба PDF прочитаны полностью: презентация — 9 страниц, функциональный сценарий — 7; просмотрены все изображения. Второй PDF не содержит текстового слоя и прочитан визуально. Исходные PDF не изменены. Фотографии извлечены из презентации; внешнего фотосервиса нет. Шрифты поставляются локально через npm.

Подтверждённые функции отделены от предложений в PRODUCT и DECISIONS. Допущения интерфейса не становятся правилами реального подбора и мэтчей. Геопуши, платежи, реклама и собственный чат не добавлены.

Telegram SDK загружается асинхронно: браузерный прототип работает при его недоступности. Адаптация включает размеры окна, безопасные отступы, цвета оболочки и нативную кнопку «Назад» с проверкой поддерживаемых версий. Данные Telegram не используются для подтверждения личности. Проверка внутри настоящего Telegram требует HTTPS-адреса и здесь не заявляется выполненной.

Серверные переменные в [.env.example](.env.example) предварительные и пустые; frontend их пока не использует. Секретов в клиентских `VITE_`-переменных быть не должно. Коммиты и публикация — только по отдельному разрешению.
