# Фильтр текста планов

**Текущая версия — D48 / 2026-11-23.2.** После замечаний пользователя исправлен разрыв между клиентским и серверным фильтром: все правила доступны в форме **при вводе** названия, описания и места, без отправки текста/запроса проверки на каждый символ. Ошибка исчезает при исправлении, введённое не стирается; предпросмотр/сохранение запрещённого текста блокируется. Backend независимо проверяет прямые запросы.

Пользователь отдельно подтвердил: нейтральные обсуждения разрешены; к запретам добавлены бордели/притоны, аварийные объекты, закрытые крыши и проникновение на стройки. Сами по себе «стриптиз» и «наркотики» вне нейтрального контекста отклоняются. Разрешены обычные бары, музеи, открытые смотровые площадки, официальные экскурсии и медицинские/образовательные обсуждения в распознаваемых конструкциях.

Русский словарь мата расширен до **8229 форм**, английский — 58; это отдельно от словоформ локаций/наркотиков и их фразовых правил. Добавлены склонения, стриптизёр/стриптизёрша, дома терпимости, наркоточки/нарколаборатории, недострои, заброшенные шахты/станции/бункеры/тоннели/коллекторы и другие сооружения. Проверяются написания по буквам, с точками/дефисами, простые повторения, омоглифы и распространённый транслит. Обещания распознать абсолютно любое придуманное написание или произвольный контекст нет.

Подтверждённое решение **D47**, 23.11.2026. Пользователь согласовал расширение: мат, прямые оскорбления, угрозы, призывы к насилию/ненависти, предложения наркотиков, платных сексуальных услуг и мошенничества. Нейтральное обсуждение тем и обычные бары/алкоголь разрешены. Прежние запреты стрип-клубов и заброшенных зданий сохраняются.

## Где работает

Авторитетная проверка — backend: название, описание и место отдельно и в сочетании. Выполняется при первом сохранении, редактировании и публикации, включая старые черновики. Прямой API-запрос проверяется так же, как форма. Отказ — HTTP 422 `PLAN_CONTENT_REJECTED`, понятная причина и поля, без копирования исходного текста в ошибку или логи.

Это отклонение текста, **не бан пользователя**. Неуспешное первое сохранение не расходует дневную квоту; отклонённое редактирование сохраняет прежний текст/версию и статус. Старые опубликованные планы автоматически не отменяются и не получают фиктивное одобрение/отказ модератора. Анкеты этим изменением не затрагиваются.

Frontend использует полный публичный снимок серверных правил `frontend/src/config/contentPolicy.generated.json`, а не отдельный урезанный список. Чистая клиентская реализация — `frontend/src/lib/contentFilter.ts`; общие примеры проверяют её согласованность с Python. Серверная ошибка по-прежнему показывается при отказе API. Дизайн, фотографии, регистрация и механика планов не меняются.

## Состав и расширение

| Файл backend/src/poidem/services | Назначение |
| --- | --- |
| content_vocabulary.py | Русские семейства, окончания и английские слова; версия POLICY_VERSION |
| content_language.py | Полные слова, транслит, маскировки и ограниченные нейтральные ссылки на термин/название |
| content_context.py | Явные угрозы, оскорбительные конструкции и опасные предложения; объяснения отказа |
| content_places.py | Формы названий локаций/наркотиков и явно ограниченного доступа |
| content_policy.py | Экспорт публичных данных/регулярных выражений для frontend |
| plan_content.py | Общая серверная проверка полей |

В версии `2026-11-23.1` **3732 русские формы и 58 английских**, без подсчёта вариантов транслита/маскировок. Это конечный набор форм по основам и окончаниям, а не полный словарь языка или оценка качества распознавания. Добавлены семейства основных матерных корней, производные, грубые оскорбления, английский мат и уничижительные обозначения. Нейтральные слова о национальности, ориентации, здоровье и анатомии сами по себе не запрещены.

Нормализация: Unicode NFKC/casefold, е/ё для сравнения, скрытые символы/комбинируемые знаки, похожие буквы, распространённый транслит, цифровые замены, повторные буквы, разделение букв пробелами/пунктуацией и внутренние маски `*`. Исходный ввод не переписывается. Склейка ограничена короткими фрагментами, маски — длиной/числом замен; глобального удаления всех пробелов нет. Повторные кандидаты проверяются один раз в пределах вызова, без долгоживущего кэша пользовательских текстов.

«Тупой нож», животные и древесные чурбаны не запрещены сами по себе: для неоднозначных слов проверяется прямое оскорбительное обращение. Полные слова и тесты защищают «педикюр», «подстрахуй», «Мандельштам», «мандарины», «стрипсы», «коктейль», «потребность».

Для расширения добавьте семейство/словоформы или узкую фразу, измените POLICY_VERSION, добавьте разрешённые/отклоняемые примеры в `backend/tests/fixtures/content_cases.json` и выполните экспорт. Проверка `test_frontend_policy_is_generated_from_current_backend` обнаруживает устаревший клиентский снимок. Playwright проверяет тот же корпус и все 8287 матерных/оскорбительных форм. Не добавляйте поиск короткого корня внутри всех слов или сторонний список без проверенной лицензии.

```powershell
.\backend\.venv\Scripts\python.exe .\scripts\export_content_policy.py
.\backend\.venv\Scripts\python.exe .\scripts\export_content_policy.py --check
```

Экспорт не читает .env/БД и не включает пользовательские данные. JSON хранится в репозитории как публичный артефакт; стандартный Cloudflare build `npm run build` из frontend **не требует Python**. При вводе не выполняются серверные запросы и не расходуется квота. Пока идет ввод незаконченного слова, фильтр не запрещает его по короткому фрагменту.

## Примеры границ

| Отклонить | Разрешить |
| --- | --- |
| Мат, включая распространённый транслит/маскировку | Обычный бар, вино, коктейль |
| «Стриптиз», «стриптиз-клуб», «наркотики», «наркота» | «Лекция о стриптизе», «лекция о вреде наркотиков» |
| «Бордель», «публичный дом», «наркопритон» | История борделей, музей старого завода |
| Аварийное здание, закрытая крыша, проникновение на стройку | Открытая смотровая площадка, официальная экскурсия |
| «Я тебя убью» | «Убью время за настольной игрой» |
| «Купим кокаин», «продажа наркотиков» | «Лекция о вреде наркотиков», «не продаю наркотики» |
| «Секс за деньги», «услуги эскорта» | «Разговор о сексе и здоровье», исторический эскорт кораблей |
| «Создадим фишинговый сайт», «разведём на деньги» | «Как распознать мошенничество», защита от фишинга |
| «Ты крыса», «ты тупой» | Книга о крысе, тупой нож |
| Опасное предложение после безопасной фразы | Явное обсуждение значения конкретного слова, роман «Идиот» |

Отрицание или слово «лекция» не отключают весь фильтр: учитывается ближайшая конструкция и конкретный фрагмент. «Не продаю наркотики, но купим кокаин» отклоняется. Нейтральная ссылка на одно слово не освобождает остальной текст от проверки.

Это лексические правила, **не понимание произвольного контекста**. Возможны пропуски нового сленга, сложных перефразировок/маскировок и ложные срабатывания в незнакомых цитатах/названиях. Не обещаем распознать каждую угрозу или гарантировать безопасность встречи. Жалобы, блокировки, ручная модерация и согласование её стадий остаются отдельным этапом.

## Почему без новой библиотеки

Изучены официальные материалы [profanity-filter](https://github.com/rominf/profanity-filter) и его [зависимости](https://github.com/rominf/profanity-filter/blob/master/setup.py): архивированный проект требует Pydantic <2 и spaCy <3, что не подходит текущему backend. [better_profanity](https://github.com/snguyenthanh/better_profanity) позволяет загружать пользовательский словарь, но не задаёт согласованные русские правила/контекст. Готовые списки вслепую не подключались.

Используются собственные локальные данные, без новых зависимостей, внешних API, сетевого анализа пользовательского текста или копирования стороннего словаря. Причины отказа остаются проверяемыми.

Команды из корня репозитория в PowerShell:

```powershell

.\backend\.venv\Scripts\python.exe -m pytest -p no:cacheprovider --basetemp $filterTestTemp -c .\backend\pyproject.toml .\backend\tests -q

Push-Location backend

Push-Location frontend

npm run build
npm run test:production
```

Новая папка basetemp обходит конфликт прав старого Windows pytest temp/cache; кэш отключён, пользовательская БД не очищается. Синтетические данные используются только автоматизированными тестами. Прежние результаты этапа 4 не подменяются новым прогоном.
