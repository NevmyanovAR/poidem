Дополнительно согласована компьютерная композиция приветствия и анкеты; форма/валидация не дублируются. После уточнения пользователя требуется оптически согласовать размеры Forum/Nicoletta и ограничить заголовки доступной шириной. Отчёт — [DESKTOP_REVIEW](DESKTOP_REVIEW.md).

Финальные результаты — в FINAL_REFINEMENTS.

Ранее подготовлена ручная конфигурация Cloudflare Pages: frontend / npm run build / dist. Публикация, push и commit текущим заданием запрещены. Backend, авторизация, PostgreSQL и бот не входят в текущий этап. Реальные устройства и Telegram проверяются отдельно после согласованной публикации; клиентская симуляция не означает приёмки серверных правил.

Текущий выход: проверяемый локальный интерфейс с отдельным деморежимом. Присланный Nicoletta Script подключён, отсутствие ё разрешено пользовательским написанием е в рукописных надписях. Исходные ограничения на коммерческое использование шрифта сохраняются.

## Этап 4. Подбор, взаимный мэтч и Telegram-контакт

Дополнение R17: транзакционно ограничить отклики 15 разными людьми, исключить автора и дубликаты. Проверить одновременные 16+ запросов, повтор/подмену ID, переходы отказа/отмены по заранее согласованному Q20. Отключённая кнопка не считается защитой.

Результат: R05–R07 — совместимые кандидаты, карточки, «Пойдём?» / «Следующий», атомарное создание парного мэтча, доступ к контакту после него. Зависит от Q03–Q05.

Проверки: матрица совместимости и взаимных предпочтений, собственная анкета исключена, пропуск не равен согласию, одностороннее согласие не даёт мэтч, повторные/конкурентные запросы не создают дубликатов. Проверить утечки контакта через ответы API и доступ постороннего; вручную проверить переход в Telegram, включая отсутствие username и ограничения приватности.
