## Nicoletta Script: подключён по уточнению пользователя

Пользователь предоставил ofont.ru_Nicoletta script.ttf и затем явно разрешил е вместо отсутствующей ё, как в логотипе. Файл подключён через @font-face под именем Nicoletta Script, без конвертации и редактирования. --font-accent указывает на него; прежний Cormorant Garamond больше не загружается.

В рукописных акцентах на главной и приветствии используется «пойдем?» через е. Обычные UI-тексты, пользовательский ввод, имя проекта и оригинальные PNG не менялись. Наклон не синтезируется: используется Regular и исходная форма букв.

Проверка fontTools: Nicoletta script Regular, версия 1.000 (2005), Nikola Kovanovic, 155448 байт. Обе Unicode-таблицы не содержат U+0401/U+0451 (Ё/ё); остальные 64 русские буквы, кавычки, вопросительный знак и проверенная пунктуация присутствуют. Разрешённое написание е устраняет подстановку недостающей буквы из другого шрифта.

SHA-256 исходника и рабочей копии: 87630ce12b054970a969860b7d5b134018392812b29dd13b3c14a0396257cf6e. Файл пользователя в Downloads не изменён.

В метаданных name ID 13: «Besplatno za svaku upotrebu osim komercijalne.» — бесплатное использование, кроме коммерческого. Исходные copyright/условия сохранены рядом в public/fonts/NicolettaScript-NOTICE.txt. Текущий объём — локальная некоммерческая дипломная демонстрация; коммерческое использование этими правками не разрешается, публикация не выполнялась.

Forum и его OFL поставляются локально. Русский алфавит Forum проверен полностью; источник — [Google Fonts](https://github.com/google/fonts/blob/main/ofl/forum/METADATA.pb), [лицензия OFL](https://github.com/google/fonts/blob/main/ofl/forum/OFL.txt).

## Состояние деморежима

- poidem:demo:v1 — прежний ключ обычной анкеты и черновиков, оставлен для совместимости
- poidem:simulation:v1 — отдельное демонстрационное состояние
- poidem:demo-mode:v1 — флаг, отсутствие означает false

Обычная анкета не подставляется в демонстрацию автоматически; тестовую анкету можно явно заполнить прежней кнопкой «Заполнить примером». Публикация в деморежиме и отклик доступны после заполнения обязательной анкеты. Шесть прежних вымышленных предложений имеют авторов из DEMO_PEOPLE; редакционные INSPIRATION остаются отдельным источником идей.

Отклик содержит конкретные planId/personId, направление incoming/outgoing и статус waiting/matched/declined. На экране совпадения ровно два участника. У демонстрационных персонажей нет настоящих Telegram-контактов, действие общения открывает пояснение и ничего не отправляет.

Клиентские ограничения — поведение локального frontend, а не серверная авторизация. Реальные действия и права будут реализовываться только на следующем согласованном этапе.
