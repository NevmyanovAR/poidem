## Как проверить через Telegram

1. Открыть Mini App кнопкой бота с текущим origin из .local/quick-tunnel.json. При изменении URL обновить /setmenubutton в BotFather, полностью закрыть/открыть Mini App
2. На A: «Создать план» → ввести «Третьяковская галерея Москва» или «Кофемания Москва» → выбрать конкретный объект/адрес → заполнить будущую дату → опубликовать. Квота 3/сутки не сбрасывается. B видит чужой план с тем же местом
3. На обычном тестовом пользователе: анкета с основным фото → Настройки → Подтвердить фото → прочитать сроки/согласие → камера/жест → снимок/переснять → отправить
4. На другом аккаунте с уже назначенной moderation-ролью: /admin → Модерация → Проверка фото → сравнить → подтвердить или отклонить с причиной. Самопроверка сотрудником запрещена. Роли произвольно не назначались; существующий owner при необходимости использует прежний раздел команды
5. Проверить результат в настройках/анкете, уведомление после /start при включённых уведомлениях. При замене основного фото отметка исчезает. Изменение описания её сохраняет. Отзыв согласия сразу закрывает доступ к материалам и снимает отметку

Физическая камера Telegram iOS/Android и настоящая доставка новых событий фотоверификации требуют ручного прогона, автоматизация их не подтверждает. Нет автоматического одобрения: решение принимает человек. Работа Places зависит от сети и лимитов ключа; ручная очередь отсутствующих мест отложена по разрешённому объёму 11А.
