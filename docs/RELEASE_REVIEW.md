## Исправления

- На мэтче до 430 px оригинальные PNG-бокалы располагаются в отдельной строке перед заголовком. Проверяются границы текстовых фрагментов через DOM Range, включая рукописный em, а не только h1 или z-index. Заголовок остаётся 69 px, PNG — без перекраски/фильтров и с исходными пропорциями 2:1. Выше 430 px сохранены прежние позиционирование/размеры/шрифты
- На главной Unicode-звёздочка заменена SVG Asterisk из уже установленного lucide-react. Сохранены назначение, размеры, координаты, поворот и #B8E4FF. Остальные иконки не менялись
- На /home добавлена исходная gallery.jpeg с парой в галерее, отдельный слой blur(2px) и мягкие градиенты с базовым #550707. Текст/логотип/кнопки остаются резкими; новых текстовых блоков и действий нет. Кнопка поиска по-прежнему ведёт на /catalog. Сохранены композиция и нижняя навигация. Приветствие / не изменялось

Токены, оригинальные PNG, шрифты и другие утверждённые элементы сохранены. Упоминание трёх допустимых цветов в последнем запросе не требует добавлять насыщенный голубой к элементам, которые уже были светло-голубыми; перекраски не было.

## Проверки

- npm run typecheck — успешно
- npm run lint — успешно
- npm run build — успешно, одна production-сборка в frontend/dist
- npm run test:production — 39/39 успешно: прежние формы/навигация/деморежим/согласия/лимиты, новые визуальные сценарии и отсутствие горизонтальной прокрутки
- npm run test:devices — окончательный повтор 4/4 успешно: WebKit с параметрами iPhone 13 и Chrome с параметрами Pixel 5, пять мобильных ширин и скриншоты
- На 320/360/375/390/430 px проверены физический зазор бокалов и всех текстовых фрагментов, пропорции PNG, safe areas, SVG вместо emoji, исходное фото и раздельное размытие, поиск планов и модальное окно общения
- Визуальные сценарии дополнительно проверяют 1366/1920 px в обычном Chrome. Для мэтча проверены также неизменные размеры/позиционирование при 431 и 680 px. Телефонный WebKit не растягивается до десктопных ширин
- Главная дополнительно проверяется после прохождения прежней анкеты с выключенным деморежимом
- Снимки приветствия 1366×768 и 1920×1080 совпали с исходными пиксель в пиксель. Контрольные суммы 12 PDF/фотографий и 3 PNG совпали

Первый дополнительный прогон движков дал 3/4: в WebKit завершение браузерного контекста превысило таймаут после расширения эмулируемого телефона до десктопной ширины. Ошибок геометрии/кнопок в нём не было. Телефонные проверки ограничены мобильными размерами, а десктоп остался в отдельном обычном Chrome; повтор выполнен отдельно. Этот первоначальный сбой не считается успешной проверкой.

Физические iPhone/Android и настоящий Telegram WebView не проверялись; WebKit/Chrome здесь работают в эмуляции. На проверенных снимках трёх затронутых элементов дополнительных визуальных дефектов не обнаружено.
