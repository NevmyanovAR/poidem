## Итоговое поведение

- Главная компактна; на маленьких экранах допускает прокрутку, фиксированной обрезающей высоты нет
- Каталог использует publishedPlans, который без backend пуст. Показаны отсутствие публикаций и «Создать первый план»
- Опубликованная карточка предусматривает название, место, дату/время, изображение, публичное имя автора и действие. Схема PublishedPlan отделена от локальных черновиков; серверную выдачу ещё предстоит реализовать
- Создание плана, проверка будущей даты, предпросмотр и редактирование перед сохранением работают. Сохранение создаёт только локальный черновик в «Моих планах», в каталог он не попадает
- Три прежние редакционные идеи и фотографии остались во «Вдохновении». Фото/стрелка и «Создать план здесь» открывают ту же форму с контекстом идеи. Партнёрские интеграции и новые мероприятия не добавлены
- Статические примеры и компоненты людей/мэтча сохранены. Внутренний параметр DemoProvider fixtureMode по умолчанию false; приложение его не включает. Он служит техническим заделом, а не новым пользовательским режимом или авторизацией
- Анкета, её шаги и поля, загрузка фотографии, валидация 18+ и ровно трёх интересов сохранены. Существующее явное заполнение анкеты примером сохранено; оно не регистрирует человека и не публикует план
- Основной текст белый, акценты голубые. HEX-токены #550707, #0599F6, #B8E4FF в theme.css не изменены. Встроенные цвета авторских растровых PNG сохранены без перекраски
- Пользовательский ввод не обрабатывается удалением точек: адреса, даты, числа, URL, файловые расширения и собственная пунктуация сохраняются

## Что согласовать

1. Как включать и обозначать тестовые анкеты/мэтчи, сохраняя их явное отделение от настоящих публикаций и учитывая прежнее требование убрать пометки о версии
2. Утверждённую форму вопросительного знака в крупных заголовках; шрифт самостоятельно не заменён
3. Назначение «Посмотреть пару». Предложение для обсуждения: так называть переход к уже образованной паре, а подборку кандидатов оставить отдельным действием
4. Нужен ли переход ко всем редакционным идеям: три имеющиеся карточки уже показаны во «Вдохновении». Прежняя «Все планы» ушла с удалённой подборкой главной
5. Текст миссии, если её следует разместить
6. Перед backend — какие сведения автора публичны и как устроен отклик на авторский план, взаимное согласие и доступ к контактам. Реальная регистрация/публикация потребуют следующего серверного этапа

Проверены отсутствие и поздняя загрузка SDK, пустой initData и работа без API-запросов. Запросы локальной антивирусной инструментации не приписываются приложению; защита не отключалась.

Сетка обхода: 320, 390, 768, 1440 px; отдельные проверки 320 × 568, 393 × 852, 360 × 800 с верхним отступом 59 px, нижним 34 px и боковыми 24/28 px. Просмотрены мобильные и десктопные снимки приветствия, главной, анкеты, каталога и вдохновения. При просмотре найден и исправлен выход декоративной звёздочки на 3 px на узком экране с увеличенными отступами; после исправления весь прогон повторён успешно. Снимки находятся в игнорируемой Git папке frontend/test-results.

Ограничения: физические iPhone/Android, Safari и настоящий Telegram WebView не запускались. Проверяется Chrome с заданными размерами и отступами, в том числе 320 × 568, 393 × 852 и 360 × 800, и имитированный Telegram bridge. Отключённые fixture-экраны сохранены технически; их интерактивный показ не заявляется согласованным пользовательским сценарием.

## Локальный просмотр

Из корня репозитория:

```powershell
cd frontend
npm ci
npm run dev
```

Адрес: http://127.0.0.1:5173/ — приветствие; http://127.0.0.1:5173/home — главная. Если зависимости уже установлены, npm ci повторять не нужно. Для просмотра собранного dist: npm run preview, http://127.0.0.1:4173/. Проверочные команды: npm run typecheck, npm run lint, npm run build, npm run test:production.
